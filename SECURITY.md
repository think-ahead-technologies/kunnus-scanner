# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's security advisory
workflow: open the [**Security** tab](https://github.com/think-ahead-technologies/kunnus-scanner/security)
of this repository and click **Report a vulnerability**.

Do **not** open a public issue for anything you believe has security impact —
give us a chance to fix it first.

What to include:

- A description of the issue and its impact.
- Steps to reproduce (a minimal input file, image, or command line is ideal).
- The kunnus version (`kunnus --version`) and platform.

We will acknowledge your report within **5 business days** and keep you
informed as we triage and fix. We credit reporters in the release notes unless
you prefer otherwise.

## Supported versions

Only the **latest release** receives security fixes. kunnus-scanner is a
standalone binary with no state to migrate — upgrading is replacing the
binary — so we do not backport patches to older versions.

## Verifying release artifacts

Every release ships with [SLSA Build Level 2](https://slsa.dev/spec/v1.0/levels)
provenance as [GitHub artifact attestations][attestations]: Sigstore-signed
in-toto statements, stored in GitHub's attestations API and (for images) beside
the image in the registry. Provenance proves an artifact was built by this
repository's release workflow from a specific commit — not tampered with or
built elsewhere. Verify with the GitHub CLI.

[attestations]: https://docs.github.com/en/actions/how-tos/secure-your-work/use-artifact-attestations/use-artifact-attestations

### Release archives and packages

Provenance covers the `.tar.gz`/`.zip` archives, the `.deb`/`.rpm` packages,
the checksums file and the SBOM:

```sh
gh attestation verify kunnus_linux_amd64.tar.gz \
  -R think-ahead-technologies/kunnus-scanner
```

### SBOM

Each release carries a CycloneDX SBOM of the released source tree,
`kunnus_sbom.cdx.json`, generated by that release's own scanner image. It is
attested against the release artifacts it describes:

```sh
gh attestation verify kunnus_linux_amd64.tar.gz \
  -R think-ahead-technologies/kunnus-scanner \
  --predicate-type https://cyclonedx.org/bom
```

The SBOM file also ships with a detached keyless
[cosign](https://github.com/sigstore/cosign) signature,
`kunnus_sbom.cdx.json.sigstore.json`:

```sh
cosign verify-blob kunnus_sbom.cdx.json \
  --bundle kunnus_sbom.cdx.json.sigstore.json \
  --certificate-identity-regexp '^https://github.com/think-ahead-technologies/kunnus-scanner/.github/workflows/goreleaser.yml@refs/tags/v.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

### Container images

Release images on `ghcr.io/think-ahead-technologies/kunnus-scanner` carry three
attestations — always verify by digest, not by tag:

- **Provenance** (release and `nightly` images):

  ```sh
  gh attestation verify \
    oci://ghcr.io/think-ahead-technologies/kunnus-scanner@sha256:<digest> \
    -R think-ahead-technologies/kunnus-scanner
  ```

- **An SBOM per platform image** (release images only), attested against the
  platform digest it describes — resolve it from the manifest list with
  `docker buildx imagetools inspect --raw`:

  ```sh
  gh attestation verify \
    oci://ghcr.io/think-ahead-technologies/kunnus-scanner@sha256:<platform-digest> \
    -R think-ahead-technologies/kunnus-scanner \
    --predicate-type https://cyclonedx.org/bom
  ```

- **A keyless cosign signature** (release images only; nightlies are unsigned):

  ```sh
  cosign verify \
    ghcr.io/think-ahead-technologies/kunnus-scanner@sha256:<digest> \
    --certificate-identity-regexp '^https://github.com/think-ahead-technologies/kunnus-scanner/.github/workflows/goreleaser.yml@refs/tags/v.*' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
  ```

Resolve a tag to its digest with
`docker buildx imagetools inspect ghcr.io/think-ahead-technologies/kunnus-scanner:<tag>`
or `crane digest`.

## Scope notes

Context that helps judge impact:

- **The scanner is offline by design.** A scan makes no network requests
  unless you explicitly opt in: `--online-licenses` (deps.dev lookups),
  `kunnus sbom container` with a remote image reference (registry pull), and
  `kunnus upload`. Anything that makes the scanner phone home outside these
  paths is a vulnerability — please report it.
- **Scan inputs are untrusted.** The scanner parses attacker-controllable
  files (lockfiles, manifests, package databases, ELF binaries, container
  images). Crashes, hangs, path traversal, or memory exhaustion triggered by
  crafted inputs are in scope.
- **Dependencies** are monitored via Dependabot and the pinned
  [osv-scalibr](https://github.com/google/osv-scalibr) revision is updated
  regularly. Vulnerabilities in scalibr itself are best reported upstream,
  but feel free to tell us too so we can ship the bumped pin.
